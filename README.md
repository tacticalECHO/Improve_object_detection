# LLM-Visual-RFT: Object Detection from Images Using Large Language Models

This repository contains the experimental implementation of my undergraduate graduation research project:

**Object Detection from Images Using Large Language Models**

The project investigates how large language models (LLMs) can improve language-guided object detection by performing semantic parsing before visual localization.

---

## Overview

Language-guided object detection models can struggle with complex natural-language queries, especially when the input contains:

- **Composite entities**, e.g. `"the girl on the surfboard"`
- **Attribute-modified entities**, e.g. `"the child in the red shirt"`
- **Multiple entities**, e.g. `"the child in red and the child in green"`

Existing approaches may fragment these expressions into separate nouns or fail to preserve important attributes.

To address this problem, this project proposes **LLM-Visual-RFT**, a two-stage framework that combines:

1. **LLM-guided semantic parsing with DeepSeek-R1**
2. **Visual object localization with Visual-RFT**

The main idea is to use an LLM to transform a complex natural-language query into structured semantic entities before passing them to the visual detector.

---

## Method

### 1. Language-Guided Semantic Parsing

DeepSeek-R1 is used to analyze the input query and extract semantically complete noun chunks.

For example:

```text
Input:
"What are the child in the red shirt and the child in the green shirt doing?"

Parsed entities:
- "the child in the red shirt"
- "the child in the green shirt"
```

The preprocessing stage includes:

- Compound noun phrase extraction
- Attribute preservation
- Structured output generation
- Duplicate removal
- Redundant entity filtering

Instead of treating individual nouns independently, the model attempts to preserve the complete semantic meaning of each target entity.

---

### 2. Visual Object Detection

The structured entities generated by the LLM are passed to the **Visual-RFT** detector for visual grounding and bounding-box prediction.

The experimental detector is based on **Qwen2-VL** with Visual Reinforcement Fine-Tuning.

Visual-RFT uses verifiable rewards for object localization, including:

- Bounding-box Intersection over Union (IoU)
- Prediction confidence
- Structured output format
- Group Relative Policy Optimization (GRPO)

## Experimental Setup

Experiments were conducted using subsets of:

- **COCO 2017**
- **Flickr30k Entities**

Two evaluation settings were constructed.

### Composite Entity Detection

A total of **500 images** were selected from COCO 2017 and Flickr30k.

Each image was paired with a query containing a composite entity or attribute-modified object.

Examples:

```text
"Where is the child in the green shirt?"

"What is the girl on the surfboard doing?"

"Where is the blue bus?"
```

### Multi-Entity Detection

A subset of **100 images** containing multiple visually distinguishable entities was used to evaluate multi-entity queries.

Example:

```text
"Find the child in the red shirt and the child in the blue shirt."
```

---

## Evaluation Metrics

The models were evaluated using:

- Precision
- Recall
- F1 Score
- Attribute Matching Accuracy (AMA)
- Bounding-box IoU

The experiments compare **LLM-Visual-RFT** against:

- Visual-RFT
- ContextDET

---

## Results

### Composite Entity Detection

| Method | Precision | Recall | F1 Score | AMA |
|---|---:|---:|---:|---:|
| ContextDET | 56.7% | 99.6% | 72.4% | 0 |
| Visual-RFT | 90.0% | 100.0% | 94.7% | 0.90 |
| **LLM-Visual-RFT** | **94.9%** | **100.0%** | **97.4%** | **0.98** |

LLM-Visual-RFT achieved an F1 score of **97.4%** and an Attribute Matching Accuracy of **0.98**, showing improved handling of composite entities and attribute-aware queries.

---

### Multi-Entity Detection

| Method | Precision | Recall | F1 Score | AMA |
|---|---:|---:|---:|---:|
| ContextDET | 79.4% | 96.8% | 87.5% | 0 |
| Visual-RFT | 95.0% | 48.0% | 63.7% | 0.85 |
| **LLM-Visual-RFT** | **97.4%** | 79.4% | **87.5%** | **0.975** |

Compared with the original Visual-RFT, the proposed language-guided preprocessing substantially improved performance on multi-entity queries.

## Limitations

The current framework still has several limitations:

- Ambiguity may occur during LLM-based semantic parsing
- Complex modifiers can occasionally lead to incorrect entity extraction
- Bounding-box localization remains sensitive to object boundaries
- LLM preprocessing introduces additional inference overhead

Future work may explore more efficient semantic parsers, joint language-vision optimization, and improved multi-entity reasoning.
